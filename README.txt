REEVA — proyecto organizado

Estructura:
- index.html: estructura de la página.
- css/styles.css: estilos y animaciones.
- js/script.js: lógica e interacciones.

Cómo abrir:
1. Abre la carpeta REEVA en Visual Studio Code.
2. Abre index.html con Live Server (si lo tienes instalado), o ábrelo directamente en el navegador.
3. Mantén las carpetas css y js junto a index.html para que las rutas funcionen.

Nota:
El JavaScript original contiene imágenes y recursos codificados en base64 dentro del propio archivo.
Se conservaron para evitar perder recursos visuales.
